## Blocker
- **B1 Unlimited flight** (`BodyRoom.ts:462`): above the jump limit `len <= prevLen + 0.05` lets every packet climb; no gravity/airtime; 0.05 m per packet is uncharged. Reproduced 29.4 m climb in 10 s, 0 violations. Fix: server-owned jump state (radial velocity + gravity), account every displacement in the budget, non-accumulating tolerance.
- **B2 Takeover resets runtime state; boss marks bypassed** (`BodyRoom.ts:299`, `npc/boss.ts:691`): new actor gets fresh protection, burn, NPC effects, heal cooldowns, attack/reload timers, special cooldowns; rejoining keeps renewing protection. Boss split marks keyed by session id → replace session, leave arena, survive (190 HP). Fix: transfer runtime state, keep protection expiry, key boss obligations by account/life.
- **B3 Combat-tagged disconnect leaves no body** (`BodyRoom.ts:368,430`): onLeave treats safe-zone presence as enough, ignores combatUntil; any travelTo skips linger (tickets never expire). Fix: safe logout needs expired combat tag; short-lived tickets consumed only by an actual handoff.
- **B4 retire() skips system leave hooks and TURN revocation** (`BodyRoom.ts:390,359`): actor deleted before client closes → onLeave returns early → voice/quest sessions leak. Fix: one idempotent removal path running all system leave hooks exactly once.
- **B5 Old reservations bypass identity/travel checks** (`matchmaking.ts:99`, `BodyRoom.ts:235`): reserve as guest, save/link, consume old seat → guest account recreated and admitted; old-body reservation usable after the ticket was consumed. Fix: invalidate reservations on merge/transitions; revalidate account + travel generation in onJoin; consume tickets atomically.
- **B6 Rollback leaves memory mutations → duplication** (`BodyRoom.ts:627`): save failure rolls back the pile but the live inventory keeps the item; retry persisted two axes. Same pattern in drop/death/rewards. Fix: stage on copies and publish after commit (or restore on rollback); suspend the actor after persistence failure.
- **B7 Egg penalties spawn unlimited persistent NPCs** (`quests/eggs.ts:128`, `QuestSystem.ts:855`): 300 NPCs in 21 s, all persist. Fix: one bounded penalty per player/object, cooldown, room NPC cap, despawn on abandon/expiry.
